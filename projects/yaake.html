YAAKE - AI-Powered Career Platform

Comprehensive recruitment platform integrating Google Gemini AI for job seekers and recruiters, featuring AI-powered resume parsing, ATS scoring, mock interviews, and cover letter generation.

82 Repo Clones (14 days)
384 Repository Views
10+ Feature Modules
React Node.js Express MongoDB Google Gemini AI JWT RBAC RESTful APIs

The Problem

Job seekers face numerous challenges in the modern recruitment landscape: optimizing resumes for Applicant Tracking Systems (ATS), preparing for interviews, and crafting compelling cover letters. Meanwhile, recruiters struggle with efficiently screening large volumes of applications and identifying the best-fit candidates.

Traditional career platforms offer limited guidance and lack intelligent, AI-powered assistance that can provide personalized feedback and automation at scale.

The Solution

YAAKE addresses these challenges by integrating Google Gemini AI to create a comprehensive recruitment platform that serves both job seekers and recruiters. The platform combines advanced natural language processing with practical recruitment workflows to deliver measurable value.

Key Features

🤖 AI Resume Parsing

Automatically extract and analyze resume content using Google Gemini AI, identifying key skills, experience, and qualifications.

📊 ATS Scoring

Evaluate resumes against job descriptions and provide actionable ATS optimization recommendations to improve visibility.

🎯 Mock Interviews

AI-powered interview simulation with real-time feedback on answers, helping candidates prepare effectively.

✍️ Cover Letter Generation

Generate tailored, professional cover letters based on job requirements and candidate profile using AI.

🔐 RBAC & Security

Role-based access control separating user and recruiter permissions with JWT authentication and rate limiting.

🚀 RESTful Architecture

10+ feature modules with clean API design, comprehensive error handling, and scalable architecture.

Technical Architecture

YAAKE follows a modular, three-tier architecture separating presentation, business logic, and data layers:

Frontend (React)

  • Component-based architecture with React hooks for state management
  • Responsive design adapting to desktop, tablet, and mobile viewports
  • Real-time feedback during AI interactions using loading states
  • Role-specific dashboards for job seekers vs. recruiters

Backend (Node.js + Express)

  • RESTful API design with 10+ feature modules
  • JWT-based authentication with token refresh mechanism
  • Role-based access control (RBAC) middleware
  • Rate limiting to prevent abuse and manage API costs
  • Comprehensive error handling and logging

AI Integration (Google Gemini)

  • Prompt engineering for resume parsing and analysis
  • Context-aware mock interview question generation
  • Natural language processing for cover letter customization
  • ATS keyword extraction and matching algorithms

Database (MongoDB)

  • User profiles with embedded resume data
  • Job postings with detailed requirements
  • Application tracking and history
  • Interview sessions and feedback storage

The ATS scoring algorithm compares extracted skills and keywords against job requirements: 

// ATS Score calculation
const calculateATSScore = (resume, jobDescription) => {
  const resumeKeywords = extractKeywords(resume);
  const jobKeywords = extractKeywords(jobDescription);

  const matchedKeywords = resumeKeywords.filter(
    keyword => jobKeywords.includes(keyword)
  );

  const score = (matchedKeywords.length / jobKeywords.length) * 100;

  return {
    score: Math.round(score),
    matched: matchedKeywords,
    missing: jobKeywords.filter(k => !matchedKeywords.includes(k))
  };
};

Challenges & Lessons Learned

1. AI Prompt Engineering

Challenge: Initial prompts produced inconsistent JSON structures from Gemini AI, causing parsing errors.

Solution: Implemented structured prompts with explicit format specifications and added validation layers to handle edge cases.

2. API Rate Limiting

Challenge: Gemini AI API costs could escalate quickly with high usage.

Solution: Implemented request rate limiting per user, caching for frequently accessed results, and optimized prompt lengths to reduce token usage.

3. Authentication & Security

Challenge: Balancing security with user experience, especially for role-based access.

Solution: JWT with short expiration times combined with refresh tokens, plus middleware-based RBAC that's easy to extend for new roles.

4. Real-time Feedback

Challenge: AI processing can take several seconds, creating poor UX without feedback.

Solution: Implemented loading states, progress indicators, and optimistic UI updates to keep users engaged during processing.
